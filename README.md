# 🏥 Healthcare Web Application

A complete healthcare web application built using Flask, Python, and SQLite.

## 🚀 Features
- 🔐 User Signup & Login System
- 🧠 Disease Prediction using Symptoms
- 📅 Appointment Booking with Booking ID
- 📩 Contact Form with Country Code Support
- 👨‍⚕️ Admin Dashboard (Users, Patients, Appointments, Contacts)
- 🔒 Secure Admin Login using Environment Variables

## 🛠️ Technologies Used
- Python
- Flask
- SQLite
- Pandas
- HTML
- CSS
